# Minitoramento-de-Cigarrinha-do-Milho
Projeto de Agrinho 2026, nele  utilizamos visão computacional para monitorar automaticamente a cigarrinha-do-milho diretamente na lavoura. A solução captura imagens das armadilhas, realiza a contagem dos insetos e disponibiliza os dados em um dashboard interativo, contribuindo para decisões mais rápidas e sustentáveis no manejo agrícola.
